# CAM Lab Codebase

This folder contains the Continuity-Aware Memory (CAM) research prototype for execution-trace-derived context management.

Contents:
- `create_continuity_paper.py`: generates the paper document and figures.
- `cam_memory.py`: minimal CAM memory data structures and EMA update logic.

Note: this is a lightweight research prototype, not a full AppWorld/FiNER benchmark reproduction.
